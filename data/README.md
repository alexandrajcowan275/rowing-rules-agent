# Rulebook download

Download the current **Rules of Rowing** from [USRowing's official resource page](https://usrowing.org/resources/rules-of-rowing) and save it here as `usrowing-rules.pdf`.

This project was verified with the [2026 edition PDF hosted by USRowing](https://usrowing-craft-storage-production.nyc3.digitaloceanspaces.com/staging/2026ROR-Final-Web2.pdf). The PDF belongs to USRowing and is deliberately excluded from Git. Download it yourself after cloning. Do not commit the PDF or local embedding cache.

The parser indexes the numbered Rules of Racing (PDF pages 12–87 in this edition). It excludes the change summary, contents, and accompanying referee/organizer manuals. Citations use one-based PDF page numbers, not inferred page labels. Updating the PDF invalidates the embedding cache automatically; review evaluation expectations for a new edition.
